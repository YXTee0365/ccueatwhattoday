# ccueatwhattoday
中正今天吃什麼？隨機推薦中正大學周邊美食
## Features
- Automatically determines breakfast/lunch/dinner/late-night snack
- Manually switch meal types
- Randomly recommend restaurants
- Google Maps navigation
- Uses Google Sheets as a data source

- HTML
- CSS
- JavaScript
- Google Apps Script
- GitHub Pages
